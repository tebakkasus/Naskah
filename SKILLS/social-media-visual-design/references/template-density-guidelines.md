# Template Density & Information Architecture Guidelines

## Context & Signal
In social media content workflows (especially educational/academic carousels like `naskah.fk`), users may reject or pivot away from minimalist aesthetic templates if the content feels too sparse ("terlalu sedikit informasi yang di share").

## Core Principles for Information-Dense Editorial Carousels

1. **Substance Over Pure Atmosphere:**
   - Aesthetically pleasing whitespace must not result in "one sentence per slide" fluff.
   - Each content slide should deliver a concrete mechanism, rule, distinction, or takeaway.

2. **Structure of an Information-Rich Slide:**
   - **Index/Category Cue:** e.g., `01`, `02`, or Topic Tag (`METODOLOGI // DO`).
   - **Bold Headline/Rule:** The central takeaway in 3–6 punchy words.
   - **Mechanistic Explanation / Context:** 2–3 concise sentences explaining *why* or *how*.
   - **Concrete Example / Antidote:** "Contoh salah vs Contoh benar" or practical heuristic.
   - **Tactile Visual Anchor:** Cutout object or diagram to maintain visual interest without stealing reading focus.

3. **Slide Count vs Density Calibration:**
   - **5-Slide Carousel:** High density per slide (Title -> Core Problem -> 3 Comprehensive Points/Framework -> Actionable Next Step).
   - **8-Slide Carousel:** Balanced pacing (Title -> Intro/Mindset -> 5 Specific Traps/Rules -> Summary Checklist/CTA).
