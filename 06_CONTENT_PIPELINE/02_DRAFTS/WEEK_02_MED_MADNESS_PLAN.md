#### 📸 IG POST — W2-D3-IG
**Topik:** ⚔️ Case-Control vs Cross-Sectional vs Cohort — Decision Tree FK
**Format:** Carousel 5 Slides (Split Screen V2 Editorial)
**Pillar:** Academic Education
**Hook:** "Kenapa dosen FK lo cemberut kalau lo pakai Cross-Sectional buat semua jenis penelitian"

**Slide Plan:**
1. **Cover:** "Cross-Sectional Bukan Satu-satunya Desain Penelitian, Dok." (Highlight: *satu-satunya*)
2. **Split Screen:** Kapan Cross-Sectional (prevalensi, snapshot, cepet kelar) VS Kapan Case-Control (penyakit langka, OR, retrospektif).
3. **The Trap:** OR ≠ RR. Odds Ratio hanya valid di Case-Control. Relative Risk hanya dari Cohort. Mahasiswa sering kecampur → penguji langsung nge-flag.
4. **Decision Tree:** Bagan alur visual: "Penyakit jarang? → Case-Control. Mau faktor risiko prospektif? → Cohort. Mau cepet + prevalensi? → Cross-Sectional."
5. **CTA:** *"Ketik 'A' kalau Cross-Sectional, 'B' kalau Case-Control, 'C' kalau Cohort. Admin review potensi jebakan penguji di desain lo! Mau dicek lengkap? DM 'BENANG MERAH'."*

**Interactive Mechanic:** A/B/C vote di komen → admin reply spesifik per desain.

## 💬 PROTOKOL ADMIN GEN Z

### Tone Rules
- Sapaan: "Halo Dok!", "Valid bgt 😭", "Sini admin spill...", "Wah ini mah...", "Noted dok, cek DM ya"
- Emoji wajib: 🩺 😭 ☕ 💊 💀 🫡 🔬 🧠
- Inside joke FK: stase, konsulen, visite, SOCA, OSCE, blok, resep, rekam medis, koas, coass, pre-test, referat, laporan kasus, journal reading
- Smart + fun: Setiap reply harus mengandung micro-insight medis/riset, bukan cuma "semangat dok!"

### Comment-to-DM Bridge Protocol
Ketika user curhat/bingung di komen → admin reply yang helpful LALU jaring:
> "Wah ini riskan bias seleksi dok kalau sampelnya ga random. Mau admin cek draftnya? DM kata **BENANG MERAH**, gratis!"

### Golden Hour Rule
30 menit pertama setelah post live → admin wajib aktif balas komen/reply untuk boost algoritma.

### Admin DO:
- Balas dengan insight + humor
- Tanya balik ke user (bikin thread panjang di komen)
- Pin komen terbaik
- Heart setiap komen dalam 1 jam pertama

### Admin DON'T:
- Balas cuma "terima kasih! 🙏" (terlalu generic)
- Balas cuma emoji tanpa konteks
- Ghosting komen yang nanya serius
- Hard sell di kolom komentar
