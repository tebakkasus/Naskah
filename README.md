# Naskah Social OS — Content Department

Welcome to the central command hub for Naskah Social Media Content. This department operates as an independent, self-contained production system.

### 📂 Directory Key
| Folder | Description |
|--------|-------------|
| `01_STRATEGY/` | Core soul, positioning, persona, content pillars, archetypes |
| `02_BRAND_ASSETS/` | Official logos, cutouts, typography assets |
| `03_DESIGN_SYSTEM/` | Visual rulebook, carousel template system, JSON baselines |
| `04_GENERATORS/` | Python scripts to render carousels and visual graphics |
| `05_OUTPUTS/` | Generated JPGs/PNGs, concept boards, and final assets |
| `06_CONTENT_PIPELINE/` | Idea → Draft → Approved → Published workflow |
| `SKILLS/` | Agent skills tailored for social media visual design |

### 🚀 How to Run
Launch this department via the Hermes Content Profile:
```bash
hermes --profile content
```
The agent will automatically load `SOUL.md`, `AGENTS.md`, and the associated skills.

### 🎨 Brand Guidelines
- Brand Handle: `@naskah.fk`
- Primary Fonts: Poppins (ExtraBold/Bold for headlines, Medium/Regular for body)
- Primary Colors: Warm Cream (#F5F2EB), Burnt Orange (#E85929), Deep Navy (#071726)
